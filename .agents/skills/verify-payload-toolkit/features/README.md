# Feature map

The executable feature map is `scripts/fixtures/feature-map.ts`. Build checks require its keys to equal the canonical registry catalog names. This index also documents base CLI and evidence operations, which are not catalog items.

- [Packed CLI](./packed-cli.md): delivered binary help and rejected commands.
- [External registries](./external-registries.md): live Hero Split URL and namespace installation, optional known Next.js and Postgres runtime.
- [Forms](./forms.md): installed plugin/example, persistence, access, errors, admin and console notification.
- [Evidence and cleanup](./evidence.md): retained results and explicitly owned resources.
